# RaymondWrite｜编剧结构实验室

RaymondWrite 是一个面向编剧、戏文学生和写作者的中文在线工具站。网站以“把一句想法发展成可写故事”为核心，提供故事框架推荐、写作陪跑、框架库、剧本库、双语对照阅读和每日框架挑战等功能。

## 功能说明

首页采用极简写作布局，只保留框架生成器和写作陪跑模式。框架生成器支持输入一句故事核心后推荐适合的故事框架；写作陪跑模式支持输入梗概后生成 5 个不同结构方向的大纲。二级功能区包含框架库、剧本库、对照阅读和开源协作说明。剧本库采用质量优先口径，收录中戏 60 本推荐剧目、汉译/原文双版本信息、多译本比较、来源可信度标签和标准化结构拆解。

## 本地运行方式

本项目是纯前端静态站，无需后端服务。克隆仓库后，直接用浏览器打开 `index.html` 即可预览。也可以使用任意静态服务器运行，例如：

```bash
python3 -m http.server 5173
```

然后访问 `http://localhost:5173`。
