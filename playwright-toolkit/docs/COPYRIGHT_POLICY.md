# 版权与字段保护规范

## 字段分级

公开可编辑字段包括中文题名、原文题名、作者、译者、出版社、ISBN、出版年、类型标签、简介、来源链接、来源可信度、结构拆解说明。

受保护字段包括版权作品全文、版权作品大段译文、权限模型、锁定条目标记、数据 Schema、分支保护说明。认证编辑者不得修改受保护字段。

## 版权作品处理

版权作品只做索引，不收录全文。允许补充官方购买页、出版社页、豆瓣读书官方页、中国知网页等正规来源。不得提交盗版全文链接、网盘链接、扫描版链接或搜索引擎跳转链接。

## 公版作品处理

公版原文优先使用 Project Gutenberg、Internet Archive、权威图书馆馆藏。汉译版本仅在确认译本公版或获得授权时才可收录较长文本；否则只做书目信息和短段引用/说明。
